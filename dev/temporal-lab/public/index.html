Campo de visão (janela final)

O recorte baixado do IRSA é sempre 1,5× a janela, para que a reprojeção e a correção de deslocamento nunca deixem cantos sem dados.

Amostragem da grade
Sobre “qualidade”

O detalhe máximo é fixado pelo instrumento: cada pixel do SPHEREx cobre ~6,2″ do céu. Um FOV maior mostra mais céu com mais pixels, mas o mesmo detalhe por objeto; um FOV menor é um “zoom” com menos pixels. A amostragem 2× interpola a grade para 3,08″/px: a imagem fica menos serrilhada na tela, mas não ganha informação nova.
