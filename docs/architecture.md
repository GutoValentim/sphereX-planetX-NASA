# Arquitetura

Estrutura inicial do SPHEREx Time Explorer:

- `frontend/`: interface em TypeScript/TSX, com configuração reservada para Vite.
- `backend/`: aplicação Python, com módulos de rotas e serviços.
- `docs/`: documentação da arquitetura e da API.

Os arquivos são pontos de partida; as funcionalidades ainda serão implementadas.
